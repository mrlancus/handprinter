# Performance measurements

All figures below were measured on **2026-11-22 in the Linux cloud build container**:

- 4 vCPU, 15 GB RAM, no GPU.
- Headless Chromium for the browser checks.
- Warm server and warm browser cache.

**These figures are not from your desktop.** Re-run the scripts there to get real numbers for the RTX 2060 / i5-9400F machine.

## Data

Generated by `scripts/perf_seed.py`: 50 synthetic pages and **10,000 regions** (1,000 lines and 9,000 words) with mixed statuses.

## API (`scripts/perf_measure.py`, 15 warm samples each)

| Request | Median | p95 |
| --- | ---: | ---: |
| `GET /api/status` | 3.0 ms | 3.5 ms |
| `GET /api/sources` (page of 48) | 10.0 ms | 10.4 ms |
| `GET /api/regions?status=needs_review` (page of 50) | 8.6 ms | 10.1 ms |
| `GET /api/regions` at offset 9,000 | 28 ms | 30 ms |
| `GET /api/sources/{id}/regions` (200 regions) | 5.8 ms | 6.5 ms |
| `GET /api/dataset/coverage` (all 10k) | 152 ms | 163 ms |
| `PATCH /api/regions/{id}` (a review action) | 3.9 ms | 4.2 ms |
| `GET /api/regions/{id}/crop` (cached PNG) | 3.6 ms | 4.4 ms |

The sources list was 104 ms before its per-row correlated subqueries were replaced by a single grouped query.

## Browser (`scripts/perf_ui.js`, 1440×900)

| Budget | Target | Measured |
| --- | --- | ---: |
| Warm UI usable: Review queue, page image and overlay rendered | 2 s | 232 ms |
| Review action visually acknowledged: keypress `A` until the inspector shows Approved (optimistic update) | 100 ms | 4.6 ms |
| Pan and zoom: animation frames during scripted wheel zoom and drag | 60 fps | 60 fps (the rAF cap) |
| 10,000-example dataset | stays responsive | every list is paginated or bounded, and no view loads the whole dataset |

## How the budgets are kept

- **Pagination:** every list has a limit of 200 or fewer.
- **Indexes:** `regions(source_id, deleted, y)`, `regions(status, deleted)`, `regions(source_id, status)` and `jobs(status, lane, created_at)`.
- **Crops:** cached per region revision on disk and served by ID. Thumbnails and previews are generated once at import.
- **Pan and zoom:** done with a single CSS transform on a stage of image plus SVG overlay. Full resolution is loaded only past roughly 1.3× of the display preview.
- **Snapshot export:** decodes each page once, sorted by source, instead of once per example.

Recognition and model runtimes are separate from these UI budgets and are not included here.
